### Rick & Morty Universe 🌌

React Native ve Expo kullanılarak geliştirilmiş, The Rick and Morty API destekli kapsamlı bir mobil uygulama. Evrendeki karakterleri, bölümleri ve lokasyonları keşfedin!

**Kullanılan Teknolojiler:** React Native, Expo, React Navigation, Axios.
